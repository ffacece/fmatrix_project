# fmatrix 🚀
Fast and smooth Matrix digital rain implementation in C++. 
Optimized for performance and transparency.

## Features
- **Smooth Resize**: Doesn't break when you resize your terminal.
- **True Transparency**: Works perfectly with transparent terminal backgrounds.
- **White Heads**: Authentic look with bright leading characters.
- **Resource Efficient**: Written in pure C++ with ncurses.

## Installation
1. Install dependencies (ncurses):
   `sudo pacman -S ncurses`
2. Clone and build:
   ```bash
   git clone https://github.com/ffacece/fmatrix_project
   cd fmatrix_project
   sudo make install
